# Legacy robot icon archive

This directory preserves the robot icon used before the ccplant sprout/network
identity. The files were copied from `origin/main` at commit
`1bdbfb5250dbc3b98cf40b7722b83ce0bbb13243` on 2026-08-21.

These assets are historical references only and are not loaded or shipped by
the web or native applications.

## Contents

- `web/` — original 192, 256, 384, and 512 px PWA PNGs
- `native/` — original 32, 128, and 512 px PNGs plus the macOS ICNS bundle
