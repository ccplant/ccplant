# クイックスタート

このガイドでは、実行先の確認、Codexの認証、最初のセッションの作成までを案内します。

## 1. 実行先を用意する

ccplantでセッションを実行するには、利用できるPoolが必要です。契約内容に応じて、次のどちらかへ進んでください。

### Managed Poolを契約している方

Poolのセットアップは不要です。契約時に用意されたManaged Poolをそのまま利用できます。

ccplantへログインし、設定の「プール」に契約済みのManaged Poolが表示されることを確認します。

::: tip Poolが表示されない場合
画面を再読み込みしても契約済みのManaged Poolが表示されない場合は、契約先の管理者へお問い合わせください。ご自身でPoolをセットアップする必要はありません。
:::

### Managed Poolを契約していない方

セッションの実行基盤を用意し、Poolへ接続する必要があります。[Session Managerをセットアップする](./session-manager)へ進んでください。セットアップ後にccplantへ戻り、設定の「プール」で利用できるPoolを確認します。

## 2. Codexを認証する

1. ccplantの設定を開き、個人設定の「Codex 認証」へ進みます。
2. 「デバイス認証を開始」を選択します。
3. 表示されたURLをブラウザで開き、表示されたコードを入力してOpenAIアカウントで認証します。
4. ccplantへ戻り、「認証が完了しました」と表示されるまで待ちます。認証情報は個人の`auth.json`として保存され、セッション開始時に自動で配置されます。

::: warning デバイスコードを共有しない
表示されたデバイスコードは、チャットやIssueなどへ貼り付けないでください。身に覚えのない認証要求はキャンセルしてください。
:::

チームで共有する認証情報を登録する場合は、設定のスコープを対象チームへ切り替えてから同じ操作を行います。チームの権限や運用ルールに従ってください。

デバイス認証を開始できない場合は、管理者へ利用可否を確認してください。手元に有効な`~/.codex/auth.json`がある場合は、「手動でアップロード」から登録することもできます。

## 3. セッションを作成する

1. 画面上部の「新しいセッション」を選択します。
2. 「初期メッセージ」に、エージェントへ依頼する内容を入力します。この項目は必須です。
3. コードを使う場合は、「対象リポジトリ」に`owner/repository`形式で入力します。必要に応じてブランチまたはPull Request番号も指定します。リポジトリを指定しない場合は一般的なチャットとして開始されます。
4. 必要に応じてセッションプロファイルを選択します。初回は「自動選択」のままでも構いません。
5. 「その他の設定」を開き、エージェントタイプで「Codex ACP」を選択します。複数のPoolがある場合は、ここで実行Poolを指定できます。未指定の場合は利用可能なPoolから自動選択されます。
6. 「セッションを開始」を選択します。

セッションの作成が完了するとセッション一覧へ移動します。起動処理が終わったらセッションを開き、Codexからの応答を確認してください。以降はメッセージを追加して作業を継続できます。

::: tip よく使う設定をまとめる
エージェント、モデル、Pool、環境変数などを毎回指定する場合は、セッションプロファイルとして保存しておくと再利用できます。
:::
