# ccplantとは

ccplantは、複数のAI coding agentセッションを作成・接続・運用するためのオープンソース基盤です。手元で始めた構成を、同じコンポーネントのままチームやKubernetes環境へ広げられます。

## 解決すること

- エージェントごとに分かれたプロセスとワークスペースの管理
- ブラウザやデスクトップからのセッション再接続
- チーム向けの認証、設定、永続化、可観測性
- APIやWebhookを使った既存ワークフローとの連携

## コンポーネント

| コンポーネント | 役割 | 実装 |
| --- | --- | --- |
| backend | API、認証、セッションのライフサイクルとルーティング | Go |
| frontend | セッション一覧、チャット、設定、運用UI | Next.js |
| native | ローカル実行環境を扱うデスクトップUI | Tauri + React |
| charts | Kubernetesへの配布と構成管理 | Helm |

## 向いているケース

個人のリモート開発環境から、複数ユーザーがエージェントを共有するチーム基盤までを想定しています。まずDocker Composeで体験し、永続化・認証・Kubernetes実行を必要に応じて追加できます。
